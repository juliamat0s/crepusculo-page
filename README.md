# Crepúsculo — Guia da saga

Landing page sobre a saga Crepúsculo, desenvolvida para a **Atividade 2 — Landing Page HTML, CSS e JavaScript Básico** do curso de Front-end PROA Transforme-se com a Serasa.

## Sobre o projeto

A página reúne informações sobre a saga, seus personagens, livros e filmes, além de uma linha do tempo e curiosidades. O menu permite navegar pelas seções, e o botão **Mudar tema** alterna entre os temas escuro e claro.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** cores, fontes, imagens e layout responsivo.
- **JavaScript:** interação do botão de mudança de tema.

O JavaScript utiliza `getElementById` para selecionar o botão, `addEventListener` para detectar o clique e `classList.toggle` para adicionar ou remover a classe `claro` no corpo da página.

## Como visualizar

1. Baixe o repositório em **Code → Download ZIP** e extraia os arquivos.
2. Abra o arquivo `index.html` no navegador.
3. Clique em **Mudar tema** para testar a interação.

Não é necessário instalar bibliotecas. A fonte Lato é carregada pelo Google Fonts quando há conexão com a internet.
